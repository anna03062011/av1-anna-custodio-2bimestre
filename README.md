# Fan Page - Britney Spears

Projeto de fan page sobre Britney Spears criado como avaliação do 2º bimestre.

## 📋 Descrição

Este é um site responsivo dedicado à cantora Britney Spears, contendo informações sobre sua história e carreira. O projeto utiliza HTML e CSS para criar uma interface moderna e elegante.

## 🎨 Características

- Design responsivo
- Paleta de cores em tons rosados
- Menu lateral de navegação
- Seções de conteúdo bem organizadas
- Layout limpo e intuitivo

## 📁 Estrutura do Projeto

```
av1-anna-custodio-2bimestre/
├── inicio.html
├── inicio.css
├── historia.html
├── historia.css
└── README.md
```

## 🖥️ Páginas

- **inicio.html** - Página inicial da fan page
- **historia.html** - Página com informações sobre Britney Spears
